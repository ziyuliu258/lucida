# Local model weights

Model weights are not tracked. The experiment configs expect the Qwen3-VL-2B-Instruct base model at `models/Qwen3-VL-2B-Instruct`, unless a config or command-line option points elsewhere.

Download model files from the publisher and follow the model's access and license terms. Keep adapters and other checkpoints under the ignored `outputs/` directory. Review `git status --ignored` before staging files if you change the ignore rules.
